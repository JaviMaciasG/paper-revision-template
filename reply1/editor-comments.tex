\section{Responses to the Editor comments}
\label{sec:responses-editor}
\reviewercomment{Please clarify the publication workflow and prepare a complete revision package.}
\response{We thank the editor for the guidance. We have revised the manual and provide responses to each point below.}
\begin{itemize}
  \Needspace{5\baselineskip}
  \item \reviewercomment{Explain how an author starts a paper without retaining the demonstration revisions.}
    \response{The introduction now describes project initialization~\cite{guide}. The new author project starts with a minimal manuscript and no active revision folders.}
  \Needspace{5\baselineskip}
  \item \reviewercomment{Use consistent names for every review round and explain the first revision.}
    \response{Sections II and VI describe the numbered manuscript and response pairs. The same round-creation command starts the first revision and subsequent rounds.}
  \Needspace{5\baselineskip}
  \item \reviewercomment{Provide separate responses for individual reviewers as well as a combined letter.}
    \responseWResponse{Section V explains that shared comment files feed both document forms. The optional bundle appends the corresponding manuscript comparison.}
\end{itemize}
