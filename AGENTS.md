# Repository Instructions

## Commit Messages

Always use [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) for commits in this repository.

Use `type(scope): description`, with an optional scope. Use `feat` for new features, `fix` for bug fixes, and appropriate types such as `docs`, `test`, `refactor`, or `chore` for other changes. Mark breaking changes with `!` before the colon or a `BREAKING CHANGE:` footer.

Split changes into coherent commits when useful, keeping required implementation, documentation, and tests together so each commit is usable.
